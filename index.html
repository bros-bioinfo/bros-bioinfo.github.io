Comment participer au Github ?

Tout le monde peut participer !

1. Demander l'accès au github

Demandez à l'un des M1 qui participe de vous ajouter en tant que contributeur sur le site.

2. Sur Linux installer la commande (tree)

Vous pouvez faire sur Ubuntu ou Debian: sudo apt-get install tree

3. Se placer dans le répertoire que l'on souhaite

Pour initialiser le github (commande): git clone https://github.com/bros-bioinfo/bros-bioinfo.github.io.git

Avant l'édition d'un fichier pour récupérer les modifications en local: git pull

Une fois l'édtition d'un fichier terminé: jithub.sh [message à ajouter décrivant la modification]

4. Enjoy !

Vous aurez sans doute d'autres question, et on est là pour vous aider. De plus il est FORTEMENT probable qu'il puisse y avoir des bugs de temps en temps. Veuillez nous en excuser.
